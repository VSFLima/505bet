## 📖 Sobre

Plataforma **505bet** de apostas e cassino: front PHP com múltiplos temas (`style_18`) e assets, API v1 (`api/v1/api.php` com `phpqrcode.php` para geração de QR Code), callbacks de pagamento, roleta configurável (`roulette_prizes_config.php`) e jogo **luckyBet**. Painel em `/admin`.

## ✨ Recursos

| Módulo | Descrição |
|---|---|
| Cassino/Apostas | `index.php`, `luckyBet/`, roleta configurável |
| PIX | `api/v1/phpqrcode.php` + `api/v1/api.php` |
| Callbacks | `callback/`, `callbackpayment/` |
| Admin | `admin/` — administradores, afiliados, atendimento |
| Dashboard | `dash/` |
| Temas | `style_18/`, `svg/`, `icons/`, assets |

## 📦 Instalação

1. Importe o banco `Banco de dados/505bet1.sql`.
2. Configure o banco em `db-config.php` na raiz (host, usuário, senha e nome do banco).
3. Acesse `/admin` com `admin@eu.com` / `qwe123` — 2FA `102030`.
4. **Troque** a senha e o 2FA.
5. Crie a conta na [ProftGames](https://proftgames.com) e use o callback `https://seudominio/proftgames/`.
